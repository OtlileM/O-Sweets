# O Sweets Website

  # Project Overview

O Sweets is a sweet business based in Pretoria Central, South Africa. This website is developed as part of the WEDES020 POE.
The website allows customers to learn about O Sweets, view available sweets, place an order, make an enquiry and contact the business.
